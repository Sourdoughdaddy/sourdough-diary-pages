# Sourdough Diary — privacy policy & support

Two static pages, served by GitHub Pages.

- `index.html` — privacy policy (English + Deutsch)
- `support.html` — support page (English + Deutsch)

These are the pages App Store Connect points at. When the app changes what it
collects, these change first — the App Store version of the policy is the one
people rely on, and a build must never be ahead of it.

Edited in the app repo under `Launch/` and copied here.
